# Иконки для расширения

Для работы расширения необходимы иконки в папке `icons/`:

- `icon16.png` - 16x16 пикселей
- `icon48.png` - 48x48 пикселей  
- `icon128.png` - 128x128 пикселей

## Создание иконок

Вы можете создать иконки любым способом:

1. **Онлайн генераторы**:
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/

2. **Графические редакторы**:
   - GIMP
   - Photoshop
   - Figma

3. **Временное решение**: 
   Создайте простые цветные квадраты с текстом "WG" или используйте любую иконку проверки орфографии.

## Временная замена

Пока иконки не созданы, расширение будет работать, но без иконки в панели инструментов браузера. Это не влияет на функциональность.
