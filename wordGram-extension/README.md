# WordGram Browser Extension

Расширение для браузера, которое автоматически проверяет орфографию и грамматику во всех полях ввода на веб-страницах.

## Возможности

- ✅ Автоматическая проверка орфографии во всех текстовых полях
- ✅ Поддержка `input`, `textarea` и `contenteditable` элементов
- ✅ Визуальная подсветка ошибок (красное подчеркивание)
- ✅ Показ предложений по исправлению при клике на ошибку
- ✅ Применение исправлений одним кликом
- ✅ Работа в реальном времени с debounce
- ✅ Настройка URL API сервера
- ✅ Включение/выключение проверки

## Установка

### Для Chrome/Edge (Chromium)

1. Откройте браузер и перейдите по адресу:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`

2. Включите "Режим разработчика" (Developer mode) в правом верхнем углу

3. Нажмите "Загрузить распакованное расширение" (Load unpacked)

4. Выберите папку `wordGram-extension`

5. Расширение будет установлено и готово к использованию

### Для Firefox

1. Откройте `about:debugging`
2. Нажмите "Этот Firefox" (This Firefox)
3. Нажмите "Загрузить временное дополнение" (Load Temporary Add-on)
4. Выберите файл `manifest.json` из папки `wordGram-extension`

## Настройка

1. Нажмите на иконку расширения в панели инструментов браузера
2. Введите URL вашего WordGram API сервера (по умолчанию: `http://localhost:8000`)
3. Нажмите "Сохранить"
4. Убедитесь, что API сервер запущен и доступен

## Использование

После установки расширение автоматически начнет работать на всех веб-страницах:

1. **Автоматическая проверка**: Когда вы вводите текст в любое поле ввода, расширение автоматически проверяет его через 1 секунду после остановки ввода

2. **Подсветка ошибок**: Слова с ошибками подчеркиваются красной линией

3. **Просмотр предложений**: Кликните на подчеркнутое слово, чтобы увидеть предложения по исправлению

4. **Применение исправления**: Кликните на одно из предложений, чтобы автоматически заменить слово

## Создание иконок

Перед установкой расширения создайте иконки. Есть два способа:

### Способ 1: Автоматическая генерация (рекомендуется)

1. Установите библиотеку Pillow:
   ```bash
   pip install Pillow
   ```

2. Запустите скрипт:
   ```bash
   python create_icons.py
   ```

Скрипт создаст простые placeholder иконки с текстом "WG".

### Способ 2: Ручное создание

Создайте папку `icons/` и добавьте три файла:
- `icon16.png` (16x16 пикселей)
- `icon48.png` (48x48 пикселей)
- `icon128.png` (128x128 пикселей)

Можно использовать любой графический редактор или онлайн генераторы иконок.

**Примечание**: Расширение будет работать и без иконок, но без визуального представления в панели инструментов.

## Разработка

### Тестирование изменений

1. Внесите изменения в файлы расширения
2. Перейдите в `chrome://extensions/`
3. Нажмите кнопку обновления (↻) на карточке расширения
4. Обновите страницу, на которой тестируете расширение

### Отладка

- **Content Script**: Откройте DevTools на странице и проверьте консоль
- **Background Script**: Перейдите в `chrome://extensions/`, найдите расширение и нажмите "service worker" для открытия DevTools
- **Popup**: Кликните правой кнопкой на popup и выберите "Inspect"

## API совместимость

Расширение использует тот же API, что и веб-приложение WordGram:

**Endpoint**: `POST /api/spell-check`

**Request**:
```json
{
  "text": "Привет, это тект для проверки",
  "language": "ru"
}
```

**Response**:
```json
{
  "errors": [
    {
      "word": "тект",
      "position": {
        "start": 19,
        "end": 23
      },
      "suggestions": ["текст", "текут"],
      "severity": "error"
    }
  ],
  "correctedText": "Привет, это текст для проверки"
}
```

## Известные ограничения

- Расширение работает только с текстовыми полями (`input[type="text"]`, `textarea`, `contenteditable`)
- Проверка запускается через 1 секунду после остановки ввода (debounce)
- Минимальная длина текста для проверки: 3 символа
- Некоторые сайты могут блокировать работу расширений (CSP политики)
