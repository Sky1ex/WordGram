# Спецификация API для проверки орфографии

## Эндпоинт

```
POST /api/spell-check
```

## Запрос

**Content-Type:** `application/json`

**Body:**
```json
{
  "text": "Привет, это тект для проверки",
  "language": "ru"
}
```

**Параметры:**
- `text` (string, обязательный) - текст для проверки
- `language` (string, опциональный) - язык текста (по умолчанию "ru")

## Ответ

**Content-Type:** `application/json`

**Успешный ответ (200 OK):**
```json
{
  "errors": [
    {
      "word": "тект",
      "position": {
        "start": 19,
        "end": 23
      },
      "suggestions": ["текст", "текут"],
      "severity": "error"
    }
  ],
  "correctedText": "Привет, это текст для проверки"
}
```

**Структура ошибки:**
- `word` (string) - слово с ошибкой
- `position` (object) - позиция слова в тексте
  - `start` (number) - начало позиции (индекс символа)
  - `end` (number) - конец позиции (индекс символа)
- `suggestions` (array<string>) - массив предложений по исправлению
- `severity` (string, опциональный) - уровень серьезности: "error" или "warning"
- `correctedText` (string, опциональный) - исправленный текст целиком

## Примеры ошибок

**Ошибка подключения:**
- Если сервер недоступен, фронтенд обработает ошибку и продолжит работу

**Некорректный формат ответа:**
- Убедитесь, что ответ соответствует указанной структуре

## Настройка URL сервера

Создайте файл `.env` в корне проекта:
```
VITE_API_URL=http://localhost:8000
```

Или используйте переменную окружения при запуске:
```bash
VITE_API_URL=http://localhost:8000 npm run dev
```
