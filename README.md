# WordGram

Приложение для проверки орфографии с использованием ИИ модели ruT5-large.

## Структура проекта

```
WordGram/
├── wordGram-AI/          # Бэкенд (FastAPI + ruT5)
├── wordGram-backend/     # (резерв)
└── wordGram-frontend/    # Фронтенд (React + TypeScript)
```

## Быстрый старт

### 1. Запуск бэкенда

1. Перейдите в папку бэкенда:
```bash
cd wordGram-AI
```

2. Создайте и активируйте виртуальное окружение:
```bash
# Windows PowerShell
python -m venv venv
.\venv\Scripts\Activate.ps1

# Linux/Mac
python -m venv venv
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

**Если возникают проблемы с установкой pydantic (особенно для Python 3.13):**

**Вариант 1 - Используйте скрипт установки (Windows):**
```powershell
.\install.ps1
```

**Вариант 2 - Установка с предпочтением бинарных пакетов:**
```bash
pip install --prefer-binary fastapi uvicorn[standard] transformers pydantic python-multipart tiktoken sentencepiece
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

**Вариант 3 - Если ничего не помогает:**
- Установите Rust: https://rustup.rs/ (потребуется перезагрузка)
- Или используйте Python 3.11 или 3.12 вместо 3.13

4. Запустите сервер:
```bash
python main.py
```

Сервер запустится на `http://localhost:8000`

**⚠️ Важно:** При первом запуске модель ruT5-large будет скачана из Hugging Face (~3GB). 
- Это может занять 5-15 минут в зависимости от скорости интернета
- Вы увидите прогресс-бар загрузки файлов
- **НЕ ПРЕРЫВАЙТЕ** процесс загрузки (Ctrl+C)
- Если загрузка прервалась, просто запустите снова - она продолжится с места остановки
- После первой загрузки модель сохранится в кэш и последующие запуски будут быстрыми

### 2. Запуск фронтенда

1. Откройте новый терминал и перейдите в папку фронтенда:
```bash
cd wordGram-frontend
```

2. Установите зависимости (если еще не установлены):
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

Фронтенд будет доступен на `http://localhost:5173` (или другом порту, если 5173 занят)

## Использование

1. Откройте браузер и перейдите на адрес фронтенда (обычно `http://localhost:5173`)
2. Введите текст в поле для проверки
3. Ошибки будут автоматически подсвечены через 500мс после окончания ввода
4. Кликните на подсвеченное слово, чтобы увидеть предложения по исправлению

## Устранение неполадок

### Бэкенд не запускается

- **Ошибка импорта:** Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`
- **Ошибка загрузки модели:** 
  - Проверьте интернет-соединение (модель скачивается при первом запуске, ~3GB)
  - Если загрузка прервалась, просто запустите снова - она продолжит с места остановки
  - Убедитесь, что есть достаточно места на диске (минимум 4GB свободного места)
- **Предупреждения TensorFlow/protobuf:** Это нормально и не влияет на работу (предупреждения подавлены)
- **Ошибка "tiktoken is required":** Установите недостающие пакеты: `pip install tiktoken sentencepiece`
- **Ошибка токенизатора:** Код автоматически переключится на медленный токенизатор, если fast не работает
- **Порт занят (ошибка 10048):** 
  - Код автоматически найдет свободный порт (8000-8009)
  - Или завершите процесс, занимающий порт:
    ```powershell
    # Найти процесс на порту 8000
    netstat -ano | findstr :8000
    # Завершить процесс (замените <PID> на номер процесса)
    taskkill /PID <PID> /F
    ```
  - Или измените порт вручную в `main.py`

### Фронтенд не подключается к бэкенду

- Убедитесь, что бэкенд запущен (проверьте консоль - там будет указан адрес)
- Если бэкенд запустился на другом порту (не 8000), настройте фронтенд:
  1. Создайте файл `.env` в папке `wordGram-frontend`
  2. Добавьте строку: `VITE_API_URL=http://localhost:XXXX` (замените XXXX на порт из консоли)
  3. Перезапустите фронтенд
- Проверьте CORS настройки в `wordGram-AI/main.py`
- Убедитесь, что оба сервера (бэкенд и фронтенд) запущены
